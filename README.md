# 🍷 Wine Quality Predictor

A complete end-to-end Machine Learning web application that predicts the quality of red wine (score 3–8) based on 11 physicochemical properties. Built with **scikit-learn** and **Streamlit**.

---

## 📌 Project Overview

| | |
|---|---|
| **Dataset** | [UCI Wine Quality Dataset](https://www.kaggle.com/datasets/yasserh/wine-quality-dataset) — Red Wine (`WineQT.csv`) |
| **Problem Type** | Multi-class Classification (6 classes: scores 3 to 8) |
| **Model** | Random Forest Classifier |
| **Accuracy** | ~63% on test set |
| **Frontend** | Streamlit web app |

---

## ⚙️ How It Works

```
WineQT.csv
    │
    ▼  train.py
Drop 'Id' column → Split 80/20 → StandardScaler → RandomForestClassifier
    │
    ▼  saved to disk
wine_model.pkl + scaler.pkl
    │
    ▼  app.py (Streamlit)
User adjusts 11 sliders → scale input → model.predict() → display score + label
```

### Preprocessing
- **Drop `Id` column** — row identifier, not a feature
- **80/20 stratified train/test split** — preserves class proportions
- **StandardScaler** — normalises all features to mean=0, std=1 (fit on train only, applied to test and new inputs)

### Model — RandomForestClassifier
- 200 decision trees trained on bootstrap samples
- `class_weight="balanced"` to handle class imbalance (most wines score 5 or 6)
- Majority vote across all trees for final prediction

### Quality Labels
| Score | Label |
|-------|-------|
| 3 – 4 | 🔴 Bad / Low Quality Wine |
| 5 – 6 | 🟡 Average Wine |
| 7 – 8 | 🟢 Good / High Quality Wine |

## 🚀 Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/JeslynS744/Wine_QT.git
cd Wine_QT
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Train the model
```bash
python train.py
```
This generates `wine_model.pkl` and `scaler.pkl` in the project folder.

### 4. Launch the web app
```bash
streamlit run app.py
```

Open your browser at **http://localhost:8501**

---

## 🌐 Deploy on Render

1. Push this repo to GitHub
2. Go to [render.com](https://render.com) → New → Web Service
3. Connect the `Wine_QT` repository
4. Set the following:

| Field | Value |
|-------|-------|
| Runtime | Python 3 |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `streamlit run app.py --server.port $PORT --server.address 0.0.0.0` |

5. Click **Create Web Service**

> On first startup, `app.py` automatically trains the model if `.pkl` files are missing — no manual step needed on the server.

## 📊 Features Used

| Feature | Unit | Range |
|---------|------|-------|
| Fixed Acidity | g/dm³ | 4.6 – 15.9 |
| Volatile Acidity | g/dm³ | 0.12 – 1.58 |
| Citric Acid | g/dm³ | 0.0 – 1.0 |
| Residual Sugar | g/dm³ | 0.9 – 15.5 |
| Chlorides | g/dm³ | 0.012 – 0.611 |
| Free Sulfur Dioxide | mg/dm³ | 1.0 – 68.0 |
| Total Sulfur Dioxide | mg/dm³ | 6.0 – 289.0 |
| Density | g/cm³ | 0.990 – 1.004 |
| pH | — | 2.74 – 4.01 |
| Sulphates | g/dm³ | 0.33 – 2.0 |
| Alcohol | % vol | 8.4 – 14.9 |

### Top 5 Most Important Features (by Random Forest importance)
1. 🥇 Alcohol — 14.6%
2. 🥈 Volatile Acidity — 12.5%
3. 🥉 Sulphates — 12.3%
4. Total Sulfur Dioxide — 10.3%
5. Chlorides — 9.6%
